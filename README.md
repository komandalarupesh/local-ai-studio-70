# Rupesh AI Studio

Build a full-stack web app called “Rupesh LLM Studio” for creating and running my own AI assistant using open-source/local language models. “Without limitations” means user-controlled/configurable behavior, not bypassing safety, provider restrictions, or laws. Build a premium responsive AI chat UI with model/provider selection, system prompt editor, temperature/max-token controls, conversation history, streaming-style responses, markdown/code rendering, copy/regenerate, file-upload UI, settings, and model/provider management. Make the model backend replaceable: support an OpenAI-compatible API endpoint and an Ollama-compatible local endpoint. Keep secrets server-side and never hard-code API keys. Include authentication and persistent chat history with the database. Add connection testing, clear error states, onboarding, and a landing/dashboard explaining local/open-source model support. Make the core app end-to-end and production-ready.
